JAVA INHERITANCE, ABSTRACT CLASS AND AVERAGE PRACTICALS (11 PROGRAMS)

Files are numbered Q01 through Q11 and have question-related filenames.
Each .java file is standalone and contains exactly one public class whose name matches the filename.

REQUIREMENTS
- Install a Java JDK (17 or newer recommended).
- Open Command Prompt/Terminal in this folder.

RUN A PROGRAM
  javac Q01_Animal_Cat_Method_Overriding.java
  java Q01_Animal_Cat_Method_Overriding

Replace the filename/class name with the practical you want to run. For Q11, enter ten numbers when prompted.
